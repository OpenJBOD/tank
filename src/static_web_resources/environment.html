Legend

Primary Temperature Source - Which probe drives fan control and the reported temperature: Onboard (built into the board) or Header (an optional probe on the pin header). Changes take effect immediately when saved — no reboot needed.

Automatic fallback - If the selected probe is missing or disconnected (e.g. no Header probe fitted, or it is unplugged), the system automatically falls back to the other probe, and finally to the RP2040 internal sensor, so fan control keeps running. The Active source row above shows which probe is actually in use.

Enable External Fan Control - This option disables the automatic fan curve response and lets you set the fan speed manually.

Update Interval - How often (in milliseconds) the fan control system checks the temperature and adjusts fan speed. Lower values provide more responsive control but use more CPU.

Hysteresis - Temperature difference (as percentage of temperature span) required before changing fan speed. Helps prevent oscillation between fan speeds.

Fan Curve - Five temperature/fan speed points that define the fan response curve. The system uses linear interpolation between points to determine fan speed at any temperature.

Temperature Range - Valid range is -40°C to +125°C (DS18B20 sensor limits).

Fan Speed Range - 0% to 100% where 0% is off and 100% is maximum speed.

PWM frequency - Frequency of the fan's PWM control input. Intel-spec 4-wire fans expect 21-28 kHz (use 26 kHz). Some older or 3-wire-style fans respond better to lower frequencies.

Tach pulses per revolution - Standard fans emit 2 pulses per revolution. This cannot be detected automatically; if the reported RPM is exactly double or half the fan's rating, adjust it here.

Tach edges sampled - How many tach edges the controller times per measurement. Auto uses the datasheet value for the pulses-per-revolution setting; 3 edges halves the measurement window so fans idling below ~480 RPM still read, at some cost in resolution. Characterization picks this for you.

Tach range - Lowest speed the controller can report. Higher settings improve resolution for fast fans but cannot read slow ones. Characterization picks this for you.

Minimum drive - The fan curve never drives a running fan below this level (0% still means off), preventing stalls at low duty.
